## gesture_control - Intro
An advanced python application that allows the user to control the system via gestures

## Installation
```cmd
git clone https://github.com/jqvxz/gesture_control
pip install -r requirements.txt
python main.py
```

## Requirements 
- Python 3.11 or later installed
- Working Webcam / Camera connected
- Fast GPU for better experience

## Features
- Tracking of both your hands
- Execute commands or shortcuts via hand movement or gestures
- Custom commands or shortcuts
- Mouse control
